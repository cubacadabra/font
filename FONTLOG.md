# Cubacadabra FontLog

## Version 0.1.1 preview — 2026-10-02

- Clarified GPL-3.0-or-later for the project-owned creation tools and alphabet
  source while retaining SIL OFL 1.1 for distributed font software and Arimo.
- Included the GPL license alongside OFL in the reproducible source archive.
- Preserved the 0.1.0 archive. Glyph designs, coverage, and metrics are unchanged.

## Version 0.1.0 preview — 2026-09-27

- Initial preview of the Cubacadabra Regular face, based on the supplied
  square-letter references.
- Added the Latin alphabet with lowercase letters mapped to the same square
  glyph designs as uppercase, preserving lowercase character mappings.
- Added conventional digits, punctuation, and selected symbol outlines based
  on Arimo Regular: 144 Unicode characters total, including printable ASCII.
- Built TTF and WOFF2 fonts, SVG and PNG specimens, an editable browser
  specimen, and a versioned source archive with checksums.
- Verified compiled outlines, character coverage, shared borders in FreeType,
  HarfBuzz/CoreText shaping, and WOFF2 loading in Chrome at four viewport sizes.
